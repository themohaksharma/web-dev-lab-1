# Personal Portfolio Website

## About
This is my personal portfolio website created using HTML as part of my Web Development Lab Assignment 1.

## Features
- Home section with a welcome message.
- About Me section with a profile picture.
- Projects section showing sample projects.
- Technical Skills table.
- Contact form with Name, Email and Message fields.
- Navigation links to move between sections.
